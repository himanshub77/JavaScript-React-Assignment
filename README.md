# JavaScript & React Assignments

This repository contains six assignments created using **HTML, CSS, JavaScript, React, and Vite**. These assignments demonstrate basic JavaScript concepts, DOM manipulation, form validation, React components, props, controlled forms, and React state management.

---

## How to Run Assignments 1–3

Assignments 1, 2, and 3 use HTML, CSS, and JavaScript.

1. Open the assignment folder.
2. Open `index.html` in a web browser.

No additional installation is required.

---

## How to Run Assignments 4–6

Assignments 4, 5, and 6 are React applications created using Vite.

Open the required assignment folder in the terminal and run:

```bash
npm install
npm run dev
```

Then open the local URL displayed by Vite, usually:

```text
http://localhost:5173/
```
